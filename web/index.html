Protocol v0 demo

Move a file through light.

QRS streams fountain-coded binary matrices from one display to another device's camera. No network connection or acknowledgement channel is used during the transfer.

Experimental prototype: transmissions are not encrypted and should not contain sensitive data.
Send a fileTurn a file into an animated 64×64 optical stream. Receive a fileAlign the camera, collect frames and reconstruct the download.

Controlled demo conditions

Start with a file below 10 KB, high display brightness, stable devices and ordinary indoor lighting. Align the visible matrix exactly inside the receiver guide.
