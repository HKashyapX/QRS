QRS v0.2.1 · Acquisition Refinement

Move a file through light.

QRS streams fountain-coded binary matrices from one display to another device's camera. No network connection or acknowledgement channel is used during the transfer.

Experimental prototype: transmissions are not encrypted and should not contain sensitive data.
Send a fileTurn a file into an animated 64×64 optical stream. Receive a fileAuto-track the optical frame, collect symbols and reconstruct the download.

Controlled demo conditions

Start with a small file, high display brightness and ordinary indoor lighting. v0.2.1 preserves the full portrait camera frame so two independent optical lanes can use more camera pixels; single-lane compatibility remains available.
